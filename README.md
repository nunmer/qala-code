# QALA CODE

### Интерактивная карта истории улиц Астаны

> **Узнай город через историю его улиц.**

QALA CODE — образовательный цифровой проект, который превращает карту Астаны в интерактивный путеводитель по истории, культуре, географии и людям, чьи имена и понятия отражены в названиях городских улиц.

Пользователь открывает карту, выбирает улицу и узнаёт, **что означает её название, с чем оно связано и почему оно появилось на карте столицы Казахстана**.

Главная особенность проекта — собственная структурированная база данных урбанонимов, созданная в рамках исследования. На этой базе работает AI-гид, который позволяет задавать вопросы о названиях улиц естественным языком.

---

## 1. Концепция

Обычная карта отвечает на вопрос:

> **«Где находится улица?»**

QALA CODE отвечает на дополнительные вопросы:

> **«Почему она так называется?»**  
> **«Кто или что стоит за этим названием?»**  
> **«Как оно связано с историей Казахстана?»**  
> **«Какие ещё улицы относятся к этой категории?»**

Таким образом, название улицы становится точкой входа в изучение истории и культуры Казахстана.

# 2. Цели проекта

### Основная цель

Создать интерактивную цифровую карту улиц Астаны с информацией об их происхождении и историко-культурном значении.

### Дополнительные цели

- исследовать названия улиц Астаны;
- создать структурированную базу урбанонимов;
- классифицировать названия по смысловым категориям;
- визуализировать результаты исследования;
- создать AI-гид по собственной базе данных;
- разработать образовательный QR-квест;
- показать взаимосвязь городской среды, истории и цифровых технологий.

# 7. Категории урбанонимов

Для классификации улиц используется система категорий.

## 🟦 7.1. Личности

Названия, связанные с конкретными людьми.

Примеры:

- Абай;
- Қабанбай батыр;
- Кенесары хан;
- Бауыржан Момышұлы.

Возможные подкатегории:

- государственные деятели;
- военные;
- писатели;
- поэты;
- учёные;
- общественные деятели;
- деятели искусства.

---

## 🟩 7.2. География Казахстана

Названия географических объектов.

Например:

- города;
- регионы;
- реки;
- озёра;
- горы;
- степи;
- исторические территории.

---

## 🟨 7.3. История и государственность

Названия, связанные с историческими событиями, государственностью и историческими понятиями.

---

## 🟪 7.4. Литература и искусство

Названия, связанные с:

- литературными деятелями;
- произведениями;
- музыкой;
- театром;
- искусством;
- культурными явлениями.

---

## 🟧 7.5. Природа

Названия, связанные с:

- животными;
- растениями;
- природными объектами;
- ландшафтами;
- природными явлениями.


- казахское название;

# 10. Карта смыслов Астаны

Отдельный раздел проекта.

### Цель

Показать, какие смысловые категории представлены среди исследованных названий улиц.

Например:

```text
Исследовано: 100 улиц

Личности       ███████████████████ 42
География      ███████████         25
История        ████████            18
Литература     █████                10
Природа        ██                    5
```

Также должна отображаться процентная доля каждой категории.

### Важно

Статистика должна сопровождаться количеством исследованных объектов.

Если исследовано только 100 улиц из значительно большего количества, интерфейс должен явно обозначать:

> **Статистика основана на исследованной выборке из 100 улиц.**

# 12. Принцип работы AI

ИИ не должен самостоятельно формировать историческую базу проекта.

Основным источником информации является **собственная база QALA CODE**.

Архитектура:

```text
Пользователь
     │
     ▼
AI Guide
     │
     ▼
Определение намерения пользователя
     │
     ▼

     │
     ▼
Получение релевантных записей
     │
     ▼
LLM
     │
     ▼
Структурированный ответ
```

# 13. AI RAG

Для AI-гидa рекомендуется использовать подход RAG.

### Retrieval-Augmented Generation

Вместо передачи всей базы данных модели:

1. пользователь задаёт вопрос;
2. система определяет, что нужно найти;
3. выполняется поиск по базе;
4. находятся релевантные записи;
5. найденная информация передаётся LLM;
6. LLM формирует ответ.

Пример:

```text
User:

"Какие улицы названы в честь писателей?"
```

↓

```text
Query classification:

category = literature
type = personality
```

↓

```text
Database:

Абай
Мұхтар Әуезов
Сәкен Сейфуллин
...
```

↓

```text
AI:

В базе QALA CODE найдены следующие улицы...
```

# 14. Ограничение AI

AI должен отвечать только на основании доступных данных проекта, когда вопрос требует фактической информации об улицах.

Если информации недостаточно:

> «В базе QALA CODE пока нет достаточной информации об этой улице.»

AI не должен придумывать:

- исторические факты;
- происхождение названия;
- даты;
- биографии;
- источники.

Для каждой фактической записи рекомендуется хранить источники.

- авторитетные исторические ресурсы.

# 18. QR-квест

## «Прогулка по истории Астаны»

Образовательный маршрут из 10 точек.

Каждая точка содержит QR-код.

После сканирования пользователь получает:

1. информацию об улице;
2. историческую справку;
3. вопрос;
4. варианты ответа или поле для ответа;
5. переход к следующей точке.

---

## Пример

### QR №1

**Улица Абая**

Вопрос:

> Кто такой Абай и какое значение он имеет для культуры Казахстана?

---

### QR №2

**Улица Қабанбай батыр**

Вопрос:

> К какой категории относится название этой улицы?

Ответ:

> Историческая личность.

---

### QR №3

**Улица Сарыарқа**

Вопрос:

> С каким географическим понятием связано название улицы?

---

# 26. Статусы данных

Каждая запись может иметь статус:

```text
draft
review
published
```

### draft

Информация ещё собирается.

### review

Запись подготовлена и ожидает проверки.

### published

Запись доступна пользователям и AI-гиду.

Это позволяет отделить исследовательскую работу от опубликованных данных.

# 34. Сценарий демонстрации

Для защиты рекомендуется следующий сценарий.

### Шаг 1

Открыть карту.

> «Перед нами обычная карта Астаны, но каждая исследованная улица содержит дополнительный исторический слой.»

### Шаг 2

Нажать на улицу Абая.

> «Мы можем узнать, кто такой Абай, почему его имя появилось на карте столицы и с чем оно связано.»

### Шаг 3

Включить категорию «Личности».

> «Теперь карта показывает улицы, названные в честь людей.»

### Шаг 4

Открыть «Карту смыслов».

> «Мы можем увидеть, какие категории представлены в нашей исследованной базе.»

### Шаг 5

Открыть AI-гид.

Спросить:

> «Какие улицы Астаны названы в честь писателей?»

ИИ отвечает на основании собственной базы.

### Шаг 6

Показать QR-код.

> «А теперь цифровую карту можно вынести за пределы компьютера.»

Отсканировать QR-код.

### Шаг 7

Показать QR-квест.

> «Мы превратили обычную прогулку по Астане в образовательный маршрут.»

# 35. Финальная идея проекта

> **QALA CODE показывает, что карта города — это не только дороги и адреса.**
>
> За каждым названием может стоять человек, событие, место, природный объект или культурное понятие.
>
> Мы собрали эти истории в собственную базу данных, визуализировали их на карте и создали AI-гид, который позволяет исследовать город с помощью естественного языка.
>
> **QALA CODE — это способ читать историю Астаны через названия её улиц.**

- фотографии исторических мест;

- сравнение урбанонимов разных городов.
