# Исследовательские скрипты

Одноразовые скрипты, которыми получены реальные координаты улиц.
В сборку приложения они не входят.

## Как обновить расположение улиц

```bash
node scripts/fetch-osm.mjs      # выгружает геометрию улиц Астаны из OpenStreetMap
node scripts/match.mjs Абай     # ищет улицу по имени в выгрузке
node scripts/gen-locations.mjs  # строит scripts/locations.json по таблице TARGETS
```

`gen-locations.mjs` содержит таблицу `TARGETS`: slug записи → точное имя улицы
в OpenStreetMap. Для каждой улицы усредняются центры всех её сегментов -
магистраль состоит из десятков way-объектов, и одна точка по середине
описывает её лучше, чем любой отдельный сегмент.

Полученные координаты вставляются в поле `twogis_url` записи в виде ссылки
`https://2gis.kz/astana?m=<lon>%2C<lat>%2F16`. Отдельных полей широты и
долготы в базе нет: ссылка 2ГИС - единственный источник расположения.

`scripts/osm-astana.json` (1.5 МБ) в репозиторий не коммитится -
он восстанавливается запуском `fetch-osm.mjs`.
